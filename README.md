# Document Compliance Platform

A web-based platform designed to help users review documents and identify missing information.

## Setup Instructions

1. Install Node.js.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open http://localhost:3000 in your browser.

## Technologies
Next.js, TypeScript, React, and CSS.
